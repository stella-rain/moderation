# Stella Rain moderation

Public moderation data for **Stella Rain**.

- `blocklist.json` lists stages (by stage code and by content hash) and creators hidden from
  everyone in the game.
  The app downloads it at startup.
- To report a stage or creator, use the **Report** button in the game. It sends an email to
  the moderation team, or, if you prefer, opens a public issue here.
